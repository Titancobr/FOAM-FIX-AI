\begin{frame}{Problem Statement}
\justifying
Many users perform workouts without supervision, which leads to poor exercise form, wrong repetition counting, low training quality, and injury risk. Existing systems usually solve only one piece of the problem, such as pose detection or action recognition, but do not combine recognition, repetition counting, posture correction, reporting, and user progress tracking into one deployable product.

\vspace{0.3cm}
\textbf{Project goal}
\begin{itemize}
  \item detect the exercise being performed,
  \item count reps accurately,
  \item check posture in real time,
  \item generate voice and text feedback,
  \item save progress and end-of-exercise summaries.
\end{itemize}
\end{frame}

\begin{frame}{What Was Implemented from Research Papers}
\small
\begin{itemize}
  \item From MediaPipe/OpenPose papers: real-time body landmark extraction.
  \item From temporal learning papers: LSTM, BiLSTM, and Transformer sequence classification.
  \item From posture correction papers: joint-angle based biomechanical rules.
  \item From feedback-oriented papers: immediate guidance during workout performance.
\end{itemize}

\vspace{0.2cm}
\textbf{What is added beyond the papers}
\begin{itemize}
  \item exercise-wise rep counting,
  \item friendly coach-style correction,
  \item live web camera interface,
  \item database-backed user progress tracking,
  \item session reports with perfect reps, corrected reps, and common mistakes.
\end{itemize}
\end{frame}

\begin{frame}{Dataset Used}
\small
\justifying
The project is trained on processed pose-sequence data. Each training sample is a \textbf{30-frame sequence}, and each frame contains \textbf{132 features} derived from detected body landmarks.

\vspace{0.2cm}
\textbf{Processed dataset summary}
\begin{itemize}
  \item total sequences: \textbf{1140}
  \item sequence shape: \textbf{\((1140, 30, 132)\)}
  \item classes: \textbf{6}
\end{itemize}

\textbf{Class distribution}
\begin{itemize}
  \item barbell\_squat: 152
  \item bicep\_curl: 225
  \item hammer\_curl: 78
  \item lateral\_raise: 170
  \item pull\_up: 212
  \item push\_up: 303
\end{itemize}
\end{frame}

\begin{frame}{Video Count vs Sequence Count}
\justifying
The model is trained on pose sequences, not directly on raw videos. One exercise video can generate multiple valid 30-frame windows, so the number of processed sequences is usually greater than the number of source videos.

\vspace{0.2cm}
\textbf{Example}
\begin{itemize}
  \item hammer\_curl videos added by user: 19
  \item processed hammer\_curl sequences in dataset: 78
\end{itemize}

\vspace{0.2cm}
This is expected because one video may produce several usable training windows after preprocessing.
\end{frame}

\begin{frame}{Preprocessing, Training and Evaluation Pipeline}
\small
\textbf{Preprocessing}
\begin{enumerate}
  \item collect exercise videos,
  \item extract pose landmarks using MediaPipe,
  \item flatten frame-wise landmark features,
  \item create 30-frame windows,
  \item store processed dataset in \texttt{exercise\_sequences.npz}.
\end{enumerate}

\textbf{Training}
\begin{enumerate}
  \item split data using stratified train/validation partition,
  \item compute class weights,
  \item train LSTM, BiLSTM, and Transformer,
  \item save models in \texttt{models/}.
\end{enumerate}

\textbf{Evaluation}
\begin{enumerate}
  \item load trained model,
  \item predict all sequences,
  \item compute Top-1, Top-3, precision, recall, F1-score, and confusion matrix.
\end{enumerate}
\end{frame}

\begin{frame}{Joint Angles Used for Rep Counting and Correction}
\small
\begin{itemize}
  \item Elbow angle = shoulder--elbow--wrist
  \item Knee angle = hip--knee--ankle
  \item Hip angle = shoulder--hip--knee
  \item Shoulder angle = elbow--shoulder--hip
\end{itemize}

These angles are reused by:
\begin{itemize}
  \item rep counter,
  \item posture correction engine,

\begin{frame}{How the Three Models Are Used}
\small
\begin{itemize}
  \item LSTM, BiLSTM, and Transformer are trained on the same processed dataset.
  \item They are compared independently to identify the strongest architecture.
  \item The live system also supports hybrid inference:
  \begin{itemize}
    \item fast mode favors LSTM,
    \item best mode favors BiLSTM,
    \item hybrid mode fuses all three with BiLSTM weight highest,
    \item ensemble mode runs all models together.
  \end{itemize}
\end{itemize}

\vspace{0.2cm}
\textbf{Reason}
\begin{itemize}
  \item LSTM gives speed,
  \item BiLSTM gives strong temporal context,
  \item Transformer gives a high-capacity comparison model.
\end{itemize}
\end{frame}

\begin{frame}{How Accuracy is Calculated}
\small
\textbf{Top-1 Accuracy}
\[
\text{Top-1}=\frac{\text{Correct highest-confidence predictions}}{\text{Total predictions}}\times 100
\]

\textbf{Top-3 Accuracy}
\[
\text{Top-3}=\frac{\text{True class inside top 3 predictions}}{\text{Total predictions}}\times 100
\]

\textbf{Precision, Recall, F1}
\[
\text{Precision}=\frac{TP}{TP+FP},
\quad
\text{Recall}=\frac{TP}{TP+FN},
\quad
\text{F1}=2\cdot\frac{PR}{P+R}
\]
\end{frame}

\begin{frame}{Conclusion}
\justifying
FormFix AI is a real-time AI workout assistant that combines pose estimation, temporal sequence modeling, rep counting, posture correction, web deployment, and user progress tracking.

\vspace{0.3cm}
The project uses LSTM, BiLSTM, and Transformer models for exercise classification, and complements them with exercise-specific angle logic for rep counting and corrective feedback. The current analytics show strong performance, especially for push-up, pull-up, and squat classes.

\vspace{0.3cm}
The system can be further improved through better dataset balance, stricter benchmarking, and expansion to more exercises, but it already demonstrates a practical AI fitness trainer built from research ideas and deployed as a usable application.
\end{frame}
